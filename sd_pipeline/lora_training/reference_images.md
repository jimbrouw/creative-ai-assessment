## Quality Standards

### ACCEPT if:
- [ ] Clearly paper-cut or flat illustration style
- [ ] Muted, warm colour palette (greens, browns, creams, soft blues)
- [ ] Simple, readable shapes
- [ ] No text, watermarks, or signatures
- [ ] Resolution 512x512 or higher
- [ ] Clean, not blurry
- [ ] Matches 1970s British children's TV aesthetic

### REJECT if:
- [ ] Photorealistic or 3D rendered
- [ ] Anime, manga, or modern cartoon style
- [ ] Dark, gothic, or horror themed
- [ ] Highly saturated or neon colours
- [ ] Contains readable text
- [ ] Shows realistic human faces
- [ ] Too busy or cluttered
- [ ] Low resolution or blurry
- [ ] Modern digital art aesthetic

## File Naming Convention

```
{category}_{number}.png
```

Examples:
- `landscape_001.png`
- `landscape_002.png`
- `tree_001.png`
- `silhouette_001.png`
- `object_001.png`
- `border_001.png`
- `texture_001.png`

Each image needs a matching `.txt` caption file:
- `landscape_001.txt`
- `tree_001.txt`
- etc.
